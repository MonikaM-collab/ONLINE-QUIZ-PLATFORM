# ONLINE-QUIZ-PLATFORM
A real-time online quiz platform with timed questions, live leaderboard, and instant score updates.

## Abstract
This project is a real-time online quiz platform designed to improve fairness, engagement, and transparency in online quizzes. The system provides timed questions, a dynamic leaderboard, and instant score updates to enhance participant experience.

## Features
- Per-question countdown timer
- Real-time leaderboard display
- Instant score update after each question
- User-friendly quiz interface

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL (phpMyAdmin)
- Operating System: Windows 11

## Objective
To conduct fair and engaging online quizzes by enforcing strict time limits, providing live ranking updates, and showing instant scores.

## Expected Outcome
The platform ensures equal time for all participants, improves competition through live leaderboards, and increases transparency with immediate score feedback.
